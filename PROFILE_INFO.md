# Perfil objetivo

Fuente: Plantilla BD Ingenieros Informáticos.  
Persona: Jesús David León Chito.

## Rol

**AI Engineer / AI Developer**

El rol combina ingeniería de IA agéntica (agentes, tool calling, RAG, LLMs) con automatización empresarial (RPA, UiPath, Power Automate), backend, cloud y operaciones.

## Competencias del perfil

### IA agéntica y LLMs

- IA agéntica
- Tool calling
- Razonamiento y ejecución de múltiples pasos
- Arquitecturas Planner / Executor / Validator
- RAG
- Prompt engineering
- Memoria y gestión de contexto
- Evaluación y testing de LLMs
- Detección de alucinaciones
- Monitorización y detección de drift

### Ingeniería y entrega

- APIs y servicios backend
- Despliegue en producción
- AWS / Azure / GCP
- DevOps y operaciones
- Liderazgo y mentoría

### Automatización y datos

- UiPath
- Power Automate
- RPA
- Power BI
- SQL Server / Oracle

## Funciones

- Construir e implementar componentes de IA agéntica.
- Desarrollar agentes que utilizan herramientas (tool-using agents).
- Implementar flujos de razonamiento y ejecución de múltiples pasos.
- Implementar patrones de agentes: Planner, Executor y Validator.
- Convertir diseños arquitectónicos en código funcional y mantenible.
- Garantizar que el comportamiento de los agentes sea acotado, predecible y esté alineado con la intención del sistema.

## Resumen para posicionamiento

El perfil a comunicar es el de un **AI Engineer** capaz de llevar agentes de IA a producción: diseñar arquitecturas Planner/Executor/Validator, conectar herramientas, controlar contexto y calidad de LLMs, y operarlos junto a automatización RPA, cloud y datos empresariales.
